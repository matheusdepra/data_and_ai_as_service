# Dativerso Identity API (Node.js)

Implementacao do `identity-api` em Node.js, alinhada com:
- Firebase Auth (magic link) no frontend
- Membership store no Firestore

Contrato:
- `docs/api/identity-api.md`

Env vars:
- `FIREBASE_PROJECT_ID` (obrigatorio)
- `FRONTEND_BASE_URL` (opcional)
- `PORT` (default 8080)
