Version: 1.0

Status: Draft

---

# Purpose

The Dataset Overview is the first destination after dataset processing is completed.

Its purpose is not to display raw data.

Its purpose is to help users understand:

* What the dataset is
* Why it matters
* How good it is
* How it relates to other datasets
* What can be built from it

This screen should feel like reviewing the work of a business analyst, not browsing a database table.

```text

```

---

# Success Criteria

Users should be able to answer the following questions within 30 seconds:

```text
What is this dataset?

Can I trust it?

How does it relate to other datasets?

What can I build from it?

What should I do next?
```

The Dataset Overview should feel like a business intelligence briefing generated by AI rather than a traditional data catalog page.
